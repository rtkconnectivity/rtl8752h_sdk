# Realtek RTL8752H SDK v1.3.0

## Introduction
RTL8752H Series SoCs support Bluetooth 5.3 + 2.4GHz + IEEE 802.15.4(Thread/Zigbee) with ultra low power consumption. Equipped with 40MHz ARM Cortex-M0+ processor, large size Flash/SRAM, and flexible GPlOs, widely used in remote controller, Mesh smart home, small UI HMI device, low-cost wearable device, smart health & medical, smart meters, smart lock, electronic shelf label, and other products.
